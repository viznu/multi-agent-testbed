# Synthetic fixtures

These items were written for this repository to exercise the pack's prompt
assembly, verification and metric code offline. **They are not a benchmark and
they are not drawn from any published dataset.** No accuracy figure produced
against them means anything about capability.

They exist so that the code path an lm-evaluation-harness task takes is fully
tested without installing that harness, and without redistributing benchmark
data whose licence and contamination status would then need managing.
